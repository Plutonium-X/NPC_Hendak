1 INSTALLATION


Il vous faut Throne of Bhaal pour pouvoir jouer à ce mod. A ce jour, je n'ai écrit que la partie SoA mais la partie pour ToB est prévue.
Il vous faut également installer le patch ToB et les correctifs principaux du mod BG2 FIXPACK.


Pour installer Hendak, rien de plus simple:

1) Décompressez le fichier .rar dans le répertoire d'installation de BG2. Puis double-cliquez sur Setup-Hendak

2) Le mod est en français, vous n'avez pour l'instant que cette langue pour l'nstallation. Attendez que les fichiers soient installés.



Il vous suffira de double-cliquer à nouveau sur Setup-Hendak pour désinstaller le mod ou bien pour installer une version ultérieure.








2 CONTENU


Ce mod vous permet d'enrôler Hendak, le gladiateur de la Couronne de Cuivre. Vous le trouvez comme d'habitude dans sa cellule. Il vou faut d'abord finir la quête qu'il vous donne dans le jeu pour pouvoir l'enrôler.
Hendak est un barbare humain d'alignement chaotique bon. Il possède une quête propre en 3 actes pour SoA. Un quatrièeme acte est prévu pour ToB.

Vous trouverez pour ce personnage:
- 2 à 3 banters par PNJ avec les autres PNJs recrutables du jeu
- des interjections avec un grand nombre de PNJs non recrutables
- une amitié assez courte sans contrainte de race, de sexe ou d'alignement

Le mod propose également de nouveaux PNJs, des combats, des items...


3 CONSEILS

L'amitié et la quête d'Hendak sont indépendantes. Vous pouvez échouer dans l'une mais réussir l'autre.
Vous devez impérativement finir l'acte 1 d'Hendak avant de partir pour le chapitre 4. Vous saurez que vous avez réussi l'acte 1 en lisant les entrées dans le journal.
Une fois fini l'acte 3, conservez une sauvegarde avant de jouer à ToB en prévision de la suite !
