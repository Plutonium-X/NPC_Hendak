# Hendak le barbare

Vous pourrez le recruter après la quête des exclavagistes.

Particularités :
- Caractéristiques : FOR 18/48, DEX 16, CON 17, INT 10, SAG 6, CHA 12.  
- 80% de résistane au froid. 
- Ce mod inclut de nombreuses choses :  
  * plusieurs banters avec chaque compagnon de Bioware.
  * des interjections avec un grand nombre de PNJs non recrutables.
  * une courte voie de l'amitié pour n'importe quelle race/sexe.
  * une quête en 3 actes, indépendante de l'amitié.
  * une nouvelle zone, de nouveaux combats et de nouveaux objets à récupérer.
